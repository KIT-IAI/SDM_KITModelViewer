# CityGML building properties editor

The CityGML Building Property Editor is a Python plugin for viewing and editing some CityGML standard attributes — as defined in the plugin — for a selected building or building part.
The complete code, including the installable plugin archive, can be found here: [CityGML building properties editor](https://github.com/KIT-IAI/SDM_Plugin_CityGML_building_properties_editor).
