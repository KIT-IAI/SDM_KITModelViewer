# CityGML building properties editor

The CityGML Building Property Editor is a Python plugin that allows to view and edit CityGML attributes — such as bldg:function or bldg:YearOfConstruction — for a selected building or building component.
The complete code, including the installable plugin archive, can be found in the repo [CityGML building properties editor](https://github.com/KIT-IAI/SDM_Plugin_CityGML_building_properties_editor).
