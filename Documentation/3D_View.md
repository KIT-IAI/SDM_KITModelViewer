# 3D View

As well as the 3D toolbar, which provides quick access to the most important functions within the 3D window, there is also a context menu with further useful functions.

## Clipping Plane Settings

<kbd>Settings</kbd> —> <kbd>Edit Clipping Plane Settings</kbd>

In the ‘Cutting Plane’ dialog box, you can define up to 6 different cutting planes.
First, you must select a plane; then you specify a main axis along which the plane is to run; after that, you can adjust the parameters of the current plane using the sliders.
